RAJYALAKSHMI — CYBERSECURITY PORTFOLIO

PREVIEW
Extract this ZIP and open index.html in a modern browser.

INTERACTIONS
- Navigation links scroll to Home, About, Skills, What I Do, Projects, Certificates, and Contact.
- Download Resume downloads Rajyalakshmi_Resume.pdf.
- Certificate cards open a large image viewer. Add your real certificate images using the exact filenames below:
  assets/certificates/joy-of-computing-python.jpg
  assets/certificates/frontend-web-development.jpg
  assets/certificates/networking-fundamentals.jpg
  Create the certificates folder inside assets. JPG, PNG or WEBP works if you update the matching filename in index.html.
- Project Visit links currently open your GitHub repositories page:
  https://github.com/Rajyalakshmi2005?tab=repositories
  Replace each href in index.html with that project's individual GitHub repository or live website URL when available.

PUBLISH FREE WITH GITHUB PAGES
1. Create a public repository named Rajyalakshmi2005.github.io.
2. Upload the contents of the rajyalakshmi-portfolio folder (not the outer folder).
3. Open Settings > Pages.
4. Choose Deploy from a branch, select main and / (root), then Save.
5. Wait for GitHub Pages to publish your site.

Included:
